# Анонімний груповий чат-бот

Telegram-бот: кожен, хто натиснув `/start`, приєднується до спільного анонімного
чату. Усі повідомлення (текст, фото, відео, голосові, стікери, файли) розсилаються
всім іншим учасникам від імені бота — без розкриття відправника.

## Швидкий старт

1. Створіть бота через [@BotFather](https://t.me/BotFather), отримайте токен.
2. Скопіюйте `.env.example` у `.env` і заповніть:
   - `BOT_TOKEN` — токен бота
   - `ADMIN_IDS` — Telegram user_id адміністраторів через кому (дізнатись свій id — [@userinfobot](https://t.me/userinfobot))
3. Запуск через Docker:
   ```bash
   docker compose up --build -d
   ```
   або локально:
   ```bash
   pip install -r requirements.txt
   python -m bot.main
   ```

БД (SQLite) створюється автоматично при першому запуску.

## Команди

**Учасники:** лише `/start` — приєднатись до чату. Далі все, що пишете боту,
йде анонімно всім іншим.

**Адміни** (тільки user_id зі списку `ADMIN_IDS`, для решти ці команди невидимі
й не спрацьовують):

| Команда | Опис |
|---|---|
| `/help` | список адмін-команд |
| `/ban` | у Reply на повідомлення учасника — забанити автора назавжди |
| `/unban` | список забанених з кнопками для розбану |
| `/pseudonym on\|off` | перемкнути глобальний режим: `Anonymous` для всіх ⇄ стабільні `Анонім №N` |
| `/setlimit <секунди>` | анти-флуд ліміт, напр. `/setlimit 1.5` |
| `/stats` | активні/забанені учасники, кількість повідомлень за годину/добу |
| `/room` | у Reply на повідомлення учасника — почати приватну кімнату адмін↔учасник (інші учасники бачать лише сповіщення про вхід, без імені адміна) |
| `/leaveroom` | завершити активну кімнату (доступно і адміну, і учаснику; вихід одного вимикає кімнату для обох) |

Адміни самі теж пишуть у загальний чат анонімно нарівні з усіма — інші учасники
ніколи не бачать, хто саме є адміністратором.

## Як влаштована анонімність технічно

Кожне вхідне повідомлення копіюється (`copy_message`, а не `forward`, щоб не
показати оригінального відправника) усім активним, не забаненим учасникам, з
окремим підписом-псевдонімом. Бот зберігає внутрішній маппінг
"кому яка копія повідомлення дісталась → хто автор" — це дозволяє адміну через
`Reply + /ban` чи `Reply + /room` деанонімізувати конкретне повідомлення на
бекенді, лишаючись анонімним для всіх інших.
